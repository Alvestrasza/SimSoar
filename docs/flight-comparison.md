# Multi-flight comparison

The public flight area links to a comparison workspace where visitors can select two to five approved public flights.

## Views

- A combined Leaflet map renders every selected track with its own colour and line pattern.
- A metrics table compares simulator, aircraft, distance, OLC points, average speed, duration, maximum altitude, and maximum climb.
- An overlaid altitude chart aligns each profile by relative flight progress. This permits a useful visual comparison even when flight durations or recording intervals differ.

Comparisons are most meaningful for flights over the same or a similar task. The selected flight identifiers remain in the URL, making the comparison linkable and providing a stable foundation for group replay and future competition views.

Only approved, public, non-deleted flights can enter this view. Unknown, private, moderated, or deleted identifiers are ignored server-side.
