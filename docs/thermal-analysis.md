# Thermal analysis

SimSoar groups sustained positive-vario samples into thermal segments while
tolerating short interruptions. Each accepted segment stores its original
track start and end sequence, duration, altitude gain, average climb, maximum
sample climb, geographic centre, and an efficiency value.

Thermal efficiency is the average climb divided by the maximum sampled climb,
expressed as a percentage and bounded to 0–100. It indicates how consistently
the pilot converted the strongest observed climb into average climb; it is not
an aerodynamic efficiency or a comparison between different weather models.

Flight details show thermal centres on the map and shade their start/end ranges
in the altitude profile. The thermal list can be sorted by average strength or
altitude gain without changing the stored chronological sequence.
